# app-reservation
Idée d'application web pour les réservations du collège
## La réservation du matériel est trop compliqué

- Problème : C'est trop compliqué de réserver le matériel pour le programme TIM au collège
- Persona : Antoine ne sais pas comment le système marche même après ce l'avoir fait expliqué, comment ont fait pour régler se problème et simplifier les choses pour que Antoine soit capable de réserver les outils qu'il nécessite pour sont projet au CEGEP

## La solution

- Créer une application web qui marche sur tout les appareils qui peuvent accéder au web et créer un liste de tout les items avec des images en tuiles similaire à Amazon
- Fonctionnalités du MVP :
  -En tant que Antoine, je veux un site simple pour réserver mes outils afin de créer mon projet et de pouvoir les retourner tout aussi simplement après que mon projet est complet
